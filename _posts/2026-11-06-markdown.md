&ensp;__Markdown__ 의 기초를 알아보겠습니다. Markdown은 .md 파일 형식으로 저장이 되는 문서양식의 일종입니다. __Notion__, __Obsidian__, __Github__, 등등 많은 어플리케이션에서 Markdown이 사용되고 있습니다. Github에서 Readme.md로 익숙해져 있을거라고 생각합니다.\
&ensp;심지어 이 작성글도 Markdown으로 작성되었습니다..! 알아두지 않으면 끊임없이 바뀌어가는 이 세상에서 살아남기 힘들것 같네요. 우리 모두 화이팅!

## 강조 emphasis
기울이기 : `*글자* or _글자_` _글자_\
굵게 : `**글자** or __글자__` __글자__\

앞뒤로 띄어쓰기를 해야합니다. 취소선은 붙여도 됩니다.

ex)\
글을 쓸 때 강조를 하는 여러가지 방법이 있죠. 대표적으로는 글자를 __굵게하거나__ _기울이는 방법_ 이 있습니다.\
제각기 사용 방법이 다르지만 저는 __굵은 글자__ 로 강조를 하는 것을 좋아합니다.

## 리스트 list
Unordered list : `- 글자 or * 글자 or + 글자`
- 리스트1
- 리스트2
- 리스트3

Ordered list : `1. 글자`
1. 리스트1
2. 리스트2
3. 리스트3

Nested list : `띄어쓰기 x 3~4 + 리스트`
- 리스트1
    - 들여쓰기1
    - 들여쓰기2
- 리스트2
    - 들여쓰기1

Checklist : `- [ ] 빈칸 / - [x] 체크 (*, +도 가능)`
- [ ] 독서하기
- [x] 운동하기
- [x] 공부하기

※리스트의 종류를 섞어쓰면 구별이 되어버리니 주의.

## 링크 link

주소를 그대로 링크 : `<주소>` <https://wsdominance.github.io/blog>
```
<https://wsdominance.github.io/blog>
```
주소를 이름으로 링크 : `[이름](주소)` [blog](https://wsdominance.github.io/blog)
```
[blog](https://wsdominance.github.io/blog)
```
문단 안에서 한꺼번에 링크 : 
```
처음 페이지는 [HOME][1] 아카이브는 [ARCHIVES][2] 작성자에 대한 건 [ABOUT][3]
이름을 바꿔도 처음으로 [HOME2][1]. 감사합니다.

[1]:https://wsdominance.github.io/blog
[2]:https://wsdominance.github.io/blog/archives
[3]:https://wsdominance.github.io/blog/about
```
처음 페이지는 [HOME][1] 아카이브는 [ARCHIVES][2] 작성자에 대한 건 [ABOUT][3] 이름을 바꿔도 처음으로 [HOME2][1]. 감사합니다.

## 코드블럭 code

코드 앞뒤를 \`로 감싸기 `print('hello world!')`

코드 안에 \`를 넣으려면 \`\`로 감싸기 `` one`two``\
양쪽 끝에 \`를 넣고 싶으면 \`\`뒤에 띄어쓰기 `` `one`two` ``

코드 앞 뒤줄을 ``` or ~~~로 가두기

&emsp;\`\`\`\
&emsp;a = 1\
&emsp;b = 2\
&emsp;print(a + b)\
&emsp;\`\`\`

```
a = 1
b = 2
print(a + b)
```
첫째줄 ``` 뒤에 문법을 넣으면 그에 따라 강조됩니다.

&emsp;\`\`\`python\
&emsp;a = 1\
&emsp;b = 2\
&emsp;print(a + b)\
&emsp;\`\`\`

```python
a = 1
b = 2
print(a + b)
```

## 표 table

표을 만들 때는 `|` 로 구분하면 됩니다. `---`로 된 행을 넣어서 머리와 구분합니다.\
왼쪽 정렬 : `:---`, 가운대 정렬 : `:---:`, 오른쪽 정렬 : `---:`\
마지막 열 `|`을 `\`로 바꾸면 다음 행과 열이 이어집니다.\
빈칸에 `^^`를 넣어 윗칸과 병합을 할 수 있고, 내용이 있으면 병합과 동시에 열바꿈을 취할 수도 있습니다.\
칸 수를 유지하며 칸의 길이를 조절하면 병합을 옆 칸과 병합을 할 수 있습니다. 강조 형식으로 강조도 할 수 있습니다.

```
| Head1  | Headtwo | Headthree |
| ------ | ------- | --------- |
| One    | __Two__ | _Three_   |
| Four   | Five    | Six       \
| Seven  | Eight   | Nine      |
| Ten    | 길이조절로 병합      ||
| ^^     | Eleven  | Twelve    |
```
